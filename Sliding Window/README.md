## Points to remember

- part of 2 pointer 
- low and high pointers are increased, i.e. low++ allows shrinking and high++ allows expanding 
- Almost used in array and string not linked list
- having to use or mentioned about sub array or sub string (continous) not sub sequence (can be split)
- Mostly used when asked to find max, min, count, avg, sum, longest, shortest, exactly equal to k or atmost or atleast k 
- if length or size of sub array is given, then fixed window is used, if length is to be found, then dynamic might be used.
- When max has to be returned, final value to be returned has an initial value of INT_MIN and if min has to be returned then INT_MAX
